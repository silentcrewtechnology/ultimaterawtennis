# Tennis (iOS)

Нативное iOS-приложение на **SwiftUI** для любителей тенниса: локальная история матчей, конструктор турнирной сетки, карта кортов и профиль игрока. Проект лежит в монорепозитории `a-dengi-kmp` как отдельный Xcode-target.

## Стек

- **SwiftUI**, навигация через `NavigationStack` (iOS 16+) с запасным вариантом для более старых версий
- **Swinject** — DI-контейнер (`AppAssembly`)
- **Core Data** — модель `TennisModel`, матчи и кэш профиля
- **Alamofire / Kingfisher** — сеть и загрузка изображений (аватар)
- **SwiftLint** — в фазах сборки Xcode-проекта

## Описание продукта

Приложение объединяет три сценария: **запланировать и разыграть турнир** (участники и сетка), **вести учёт сыгранных матчей** и **смотреть карту кортов**. Первый запуск может показывать **онбординг**; дальше открывается основной интерфейс с вкладками.

## Фичи

### Онбординг и запуск

- Экран загрузки (`AppLoader`) и переход либо в **онбординг**, либо сразу в **главные вкладки**, в зависимости от флага завершения онбординга (`OnboardingStateStore`).

### Главный Tab Bar

1. **«Сетка»** — стартовый экран создания турнира (фон, заголовок, переход к мастеру создания).
2. **«История»** — список матчей из Core Data: просмотр деталей, свайп-удаление, кнопка **добавить матч** (создание с нуля).
3. **«Карта»** — список/карта теннисных кортов через `CourtService` (в сборке — **локальный** `LocalCourtService`).
4. **«Настройки»** — профиль, статистика, политика конфиденциальности (PDF из бандла), переход к **правилам турнира**.

### Турнир

- **Мастер создания**: название, тип сетки (**одиночный / парный** турнир), список участников, черновик сохраняется в **UserDefaults** (`UserDefaultsTournamentDraftStore`).
- **Редактор участника** — отдельный экран ввода имён (через реестр контекста навигации).
- **Сетка турнира** и **экран результата** — визуализация и завершение сценария турнира.
- **Правила турнира** — отдельный экран (`TournamentRulesView`), доступ из настроек.

### Матчи

- Модель матча: два игрока (имя/фамилия), счёт, победитель, дата, опционально **место и координаты** (привязка к локации).
- **Сервис матчей** (`MatchService`): подписка на изменения (`AsyncStream`), сохранение и удаление.

### Профиль и тема

- Профиль: имя, рост, вес, счётчики **сыграно / побед**, аватар (галерея, при необходимости сохранение во временный файл).
- Данные профиля читаются/пишутся через **Core Data**; сетевой слой (`NetworkServiceProtocol`: профиль, турниры, `uploadMatch`) заложен в архитектуру для дальнейшей синхронизации.
- Переключение **светлой/тёмной темы** через `ThemeService` и `preferredColorScheme`.

### Прочее

- Локализуемые строки (`.localized`).
- Навигация централизована: `AppRoute`, `NavigationStateModel`, фабрика экранов `DestinationViewFactory`.

## Сборка

Открыть `Tennis.xcodeproj` в Xcode и собрать target **Tennis** (iOS).
